今日要闻

1. "我正在变成 AI 盲人"

来源：cymerys.com + HN（1787312885，267 点 / 279 评，8 月 22 日凌晨）。作者描述了一种越来越普遍的体验：在 AI 生成内容爆炸的信息环境中，人们开始发展出一种类似"广告盲"的能力——自动过滤、忽略、不信任所有看起来可能是 AI 生成的内容，但同时也开始无法区分人类真诚写作与 AI 润色写作之间的差异。"我不再读长文章的第一段了，因为我不知道那是否是一个真实的人在向我说话。"

279 条评论中，大量读者分享了类似体验：
- "我现在对 LinkedIn 帖子完全免疫了，但同时对真实的工程经验分享也开始怀疑。"
- "我在评论区看到了曾经的文章里根本没有的活力——评论是 AI 最难伪造的东西。"
- "这不是盲目，是防御机制。"

编辑点评：这篇文章描述的现象有一个准确的名字：AI 信噪比崩塌引发的认知防御。当信号（真实内容）和噪声（AI 生成内容）的比例倒置，人类的认知系统开始执行"一律怀疑"的默认策略——这对真实内容创作者的伤害，和对 AI 生成内容本身的伤害一样大。

更深层的影响：信任是互联网人类互动的底层协议。"AI 盲"不只是个人体验，而是这个协议正在被侵蚀的症状。我们可能正在进入一个新均衡：评论、手写截图、视频通话、实时语音，成为"证明人类在场"的稀缺证书，而静态文字内容的默认信任度趋向于零。

2. Claudette：让 Claude 停止说话像 BuzzFeed 文章

来源：GitHub + HN（1787322712，203 点 / 143 评，8 月 22 日）。"Claudette"是一个 system prompt 工具包，通过精心设计的指令让 Claude（及其他 LLM）去除：开场白（"当然！"、"很好的问题！"）、感叹号滥用、空洞的过渡性语言（"此外，值得注意的是…"）、最后的总结段落、不必要的免责声明。项目 README 的第一句话："让 Claude 停止听起来像一个 BuzzFeed 文章。"

143 条评论中，大量开发者分享了他们自己的 prompt 工程技巧，并讨论为什么 RLHF 会导致这种"奉承性输出风格"——模型被训练成让人感觉好，而"当然！"和感叹号是低成本的正面情感信号。

编辑点评：Claudette 和昨天的 Vomit 工具在两天内先后出现，反映了同一个社区现象：模型的输出风格问题已经产生了专属的"修复工具"生态。这是用户体验摩擦到达阈值的信号——当摩擦足够大，工具会自然涌现。对模型提供商来说，这两个工具的出现是一个清晰的产品 backlog 条目：默认输出风格需要重新调校，"有帮助的 AI"不等于"讨好用户的 AI"。值得注意的是，Claudette 提到这个问题在 Claude 5 中比 Claude Sonnet 4.6 更突出，暗示能力提升可能伴随了输出风格的退化。

3. 工程师报告：用 Codex 一周的感受

来源：allaboutcoding.ghinda.com + HN（1787341908，80 点 / 84 评，8 月 22 日）。一位工程师记录了将主要 AI 编码工具从 Claude 切换到 OpenAI Codex CLI 一周的使用感受。核心对比：Codex 在大型代码库的上下文理解上更快但"理解深度浅"；Claude 在理解复杂业务逻辑上明显更好，但偶尔的长输出和冗余解释降低了效率；两者在实际完成任务的成功率上相近，但"使用体验"和"对话自然度"差异显著。

编辑点评：这类个人使用报告是市场中最真实的竞争情报。工程师不在意基准测试——他们在意的是"我的具体工作流下，哪个工具让我更顺"。Claude vs Codex 的核心差异被描述为"深度 vs 速度"，这与两个产品的设计哲学高度一致。值得关注的是 84 条评论中对"切换成本"的讨论——大量工程师表示已经在不同任务上混用多个 AI 工具，单一工具忠诚度正在下降。

4. sub-50ms 文字转语音：实时 AI 语音的新基准

来源：nari-labs.com + HN（1787327470，105 点 / 28 评，8 月 22 日）。Nari Labs 工程博客介绍如何将 Qwen3 TTS 模型的推理延迟压缩至 sub-50ms：使用流式解码（streaming decode）而非批处理；模型蒸馏将参数量降低 80% 同时保持音质；针对 Apple Silicon 的优化使用了 Metal Performance Shaders。延迟从原始的 800ms 降至 47ms。

编辑点评：47ms 是一个心理学上有意义的数字——人类感知"即时"的延迟阈值约为 100ms，47ms 进入了人类无法感知延迟的区域。这对实时语音 AI（电话 AI 助手、实时翻译、听障辅助工具）意味着从"可用"进入"自然"。结合本周早些时候的 OpenAI Ultrafast（750 tokens/秒）和 Gemini 3.7 Flash 的低延迟推进，推理速度正在全线逼近"无感知延迟"的临界值。

5. 构建完全自托管、沙盒化的 Agent 软件工厂

来源：blog.jakesaunders.dev + HN（1787329672，85 点 / 50 评，8 月 22 日）。工程师 Jake Saunders 详细记录了他如何构建一个几乎完全自托管的 Agent 开发环境：本地部署 Ollama 模型（避免云 API 成本）、Docker 沙盒隔离 Agent 执行环境、git-based 工作流追踪 Agent 提交历史、人工审批门控防止自动部署到生产环境。

编辑点评：这篇文章是"Agent 工程民主化"的典型代表——一个独立工程师用开源工具构建了大公司才有资源做的东西。更重要的是，文章中的安全设计原则（沙盒隔离、人工审批门控、每步可审计）与 Anthropic、OpenAI 推荐的 Agent 安全最佳实践高度一致，说明社区已经开始内化这些原则并付诸实践。
