## 今日要闻

### 1. 能否相信 OpenAI 保管未发表的数学证明？

来源：HN（1789022983，**856 点 / 805 评**，Sep 10 深夜 — 今日持续主导讨论）。这是本周 Navier-Stokes 争议的最关键延伸。HN 原帖提出了一个尖锐的实践问题：如果 OpenAI 的 AI 真的在处理未发表的数学研究材料（如研究员上传的草稿证明），OpenAI 的数据使用政策是否会阻止这些材料被用于训练数据？OpenAI 的隐私政策措辞使这个问题存在真实的模糊地带。

805 条评论——是点数的近一倍——将这场讨论推向了 AI 公司与科学界关系的核心：**学术研究的价值来源于其未发表状态的优先权保护，而 AI 训练数据需求与这种保护存在结构性冲突**。多位活跃的数学研究者和 CS 研究员在评论中表达了对使用 ChatGPT/Claude 处理未发表工作的明确顾虑。

同时，HN 出现了 Navier-Stokes 进展的技术后续（1789075379，176 点 / 177 评）：OpenAI 的发布材料中包含了 Lean 4 形式化证明，这被部分数学家视为真实进展的证明，但争议并未因此平息——焦点转移到了这个形式化证明是 AI 独立生成的还是人类辅助的。

**编辑点评**：这场讨论的深层价值在于它揭示了一个还没有被正式解决的制度真空：**当 AI 成为学术研究的日常工具时，学术界的知识产权保护框架还没有追上这个现实**。学者把草稿上传给 ChatGPT 寻求反馈，这个行为在技术上符合 OpenAI 的服务条款，但在学术规范上可能已经构成了将未发表研究暴露给潜在训练数据来源的行为。这不是某一家 AI 公司的问题，而是整个学术界需要集体形成新规范的问题——无论这个规范最终是"可以用，但要注意什么"，还是"不可以用于未发表工作"。

### 2. Claude 限制 18 岁以下用户：AI 的年龄门槛

来源：HN（1789123680，**576 点 / 598 评**，Sep 11）。Anthropic 宣布 Claude 的服务条款更新：claude.ai 和 Claude API 的终端用户必须年满 18 岁，开发者需要在其应用中确保未成年用户不能访问 Claude 的原始能力。这是主流前沿 AI 产品中首个明确的年龄限制政策——OpenAI 和 Google 目前对未成年人使用没有同等明确的限制。

598 条评论中，讨论高度分裂：一方认为这是过度限制，失去了教育场景；另一方认为这是负责任的做法，特别是在心理健康研究指向 AI 与青少年使用关联的背景下（OpenAI 9/8 宣布资助 AI 与青少年发展研究）；还有工程师讨论合规实施的难度（年龄核实的实际机制是什么？）。

**编辑点评**：这个政策的出现时机不是孤立的。就在两天前（9/9），OpenAI 宣布资助"AI 与青少年发展"研究；本周早些时候，Anthropic 还面临"构建监控系统"的负面报道。18 岁限制是 Anthropic 在一系列舆论压力下的一次主动政策动作，目的是**建立与 OpenAI 相比更为保守的产品边界**，从而在"负责任 AI 公司"的市场定位上与竞争对手形成差异。

实际影响很可能有限——大多数 18 岁以下用户不会因为一个服务条款更新就停止使用；真正的影响在于企业和学校客户：学校在引入 Claude 作为教育工具时，这个年龄限制意味着额外的合规负担，可能推动学校选择有明确教育版本的竞品。

### 3. Cognition SWE-2：宣称比肩 Fable 5.1 和 GPT-6 Astra

来源：HN（1789054187，441 点 / 188 评，Sep 11）。Cognition（Devin 的开发商）发布 SWE-2 模型，专注于软件工程任务，宣称在 SWE-bench 等基准上的表现可以与 Anthropic Fable 5.1 和 OpenAI GPT-6 Astra 比肩，而专项任务（代码修复、测试生成、代码审查）上有针对性优势。

**编辑点评**：Cognition 的出现是一个重要的市场信号：**专门化的代码 AI 正在挑战通用旗舰模型在特定场景的领导地位**。Fable 5.1 和 GPT-6 Astra 是通用模型，SWE-2 是专门为软件工程任务设计和微调的。在专业场景，专门化模型打败通用模型是合理的——就像医学影像 AI 在医学影像上打败 GPT-4 并不令人意外一样。这个趋势预示着 AI 模型市场将越来越清晰地分化为：旗舰通用模型（Fable、Astra、Gemini）和专业化垂直模型（代码、法律、医疗、金融），**两者面向不同场景，并非零和竞争**。

### 4. OpenAI Agents API 正式开放 + GPT-Live-1

来源：HN（1789069402，338 点 / 178 评，Sep 11）；OpenAI RSS。OpenAI 正式发布 Agents API，让开发者可以直接调用 OpenAI 平台上的 Agent 构建能力：内置的工具使用、多步骤任务规划、持久会话状态，以及与 OpenAI 工具生态的深度集成。同日，OpenAI 还发布了 GPT-Live-1——专为语音体验设计的实时语音 API，主打低延迟（声称端到端延迟低于 300ms）和自然语音风格。

**编辑点评**：Agents API 的开放意味着 OpenAI 在 Agent 基础设施层正式宣战。此前，Anthropic 的 Claude Code 和 MCP 协议已经在 Agent 工具链上积累了先发优势；Agents API 是 OpenAI 用平台资源直接回应这一优势的动作。**谁控制了 Agent 的底层 API，谁就在接下来的 Agent 应用生态中拥有最深的基础设施话语权**。

### 5. Waymo 效应：AI 正在让科研合作变少

来源：HN（1789125470，320 点 / 295 评，Sep 11）。论文分析了"AI 导致学术合作减少"的现象，将其称为"Waymo 效应"——类比 Waymo 在自动驾驶领域采取的封闭研发路线，越来越多的 AI 驱动的研究团队选择不发表中间成果、不开源工具、不进行传统的学术合作，因为**在 AI 辅助研究加速的环境下，发表即暴露竞争优势**。295 条评论中，研究员们分享了大量亲身经历：合作意愿下降、预印本发布时机更谨慎、团队越来越倾向于把关键方法留到最后才发表。

**编辑点评**：这和今天 #1 故事（OpenAI 保管未发表数学证明）构成了同一个现象的两面：AI 正在从两个方向侵蚀学术开放性——一方面，AI 公司的数据使用政策让研究者不敢共享；另一方面，AI 辅助的研究加速让团队更有动机在竞争中保持封闭。学术界的开放协作规范，是过去几十年科学进步的重要基础设施——**如果 AI 系统性地侵蚀这个基础设施，它对人类长期科学进步的影响可能远超过短期的研究加速收益**。
